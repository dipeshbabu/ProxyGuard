# ProxyGuard experiment drivers

`proxyguard/` contains the controlled studies, prospective audits, cost
planners, artifact builders, and the tabular support needed by those
workflows. The statistical library itself remains in the top-level
`proxyguard/` package.

Run drivers from the repository root with Python's module form:

```bash
python -m scripts.proxyguard.run_proxyguard_conditional_shared_target --help
```
